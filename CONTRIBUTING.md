# Contributing to renew

Thank you for your interest in renew.

The project is in early development and is **not yet accepting external
contributions** (pull requests). This will change once the core architecture
stabilizes.

In the meantime:

- **Issues are welcome.** Bug reports and feature suggestions help shape the
  project — please open an issue on the tracker.
